# Salt & Dehydration — Interactive Demo

**Live demo:** [https://salt-cell-demo.vercel.app](https://salt-cell-demo.vercel.app)

A light-mode, off-white educational site that shows how salt pulls water out of a cell (osmosis) and why eating a lot of salt feels dehydrating.

## Run it locally

Open `index.html` in a browser — no build step or server required.

```bash
# optional local server
npx serve .
# or
python3 -m http.server 8080
```

Then visit the printed URL (or `http://localhost:8080`).

## What it demonstrates

- **Live cell canvas** — raise outside salt; water particles stream out and the cell shrinks
- **Presets** — blood-like, salty snack, ocean water, hyper-salty
- **Hypotonic / isotonic / hypertonic** comparison cards
- Short copy on why high salt shifts body water and drives thirst
